Uses the same quant_reference.py pipeline as check_quant.py:
  divisor-scale quantization -> quantized weights/bias -> integer accumulation
  -> float32 requantization -> symmetric saturation -> next layer.
Saved codes are the exact codes consumed by the following node.

All 152 saved nodes are checked against TargetCall's quant_reference.py.
Agreement with the unmodified ACModelSight backend and hardware is unverified.

all_layers["Softmax"] is the full quantized pipeline output. ../output_000.npy
is the float golden quantized at the boundary and is not an integer-pipeline
reference. ReLU codes are nonnegative; int8 codes stay in [-127,127].

--mode ideal is a diagnostic quantization of independent float activations.
It must not be used for pipeline verification. Hardware Softmax lookup tables
and integer multiplier/shift approximations are outside this software reference.
